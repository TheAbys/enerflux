Home Assistant export

Read-only calculated values, served by EnerFlux from /api/v1/integrations/home-assistant/sensors.

Optional read-only export

Set HOME_ASSISTANT_READ_TOKEN in EnerFlux’s deployment environment or Kubernetes Secret. Generate a long random value, then reference the same token from Home Assistant’s secrets.yaml. EnerFlux reads and compares the token in constant time; it does not store the secret in PostgreSQL. Changing the secret and redeploying rotates it.

The export route returns calculated sensor values only and accepts no writes. Use HTTPS or keep both services on a trusted private network.
